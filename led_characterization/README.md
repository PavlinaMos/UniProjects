# LED Characterization and Converter Simulation

Project focused on LED lamp electrical characterization .

## Contents

- `simulink_model.slx`: Simulink model (power electronics simulation)
- `report.pdf`: project report

## Tools

- MATLAB + Simulink
- Simscape Electrical

## How To Run

1. Open `simulink_model.slx` in MATLAB/Simulink.
2. Run the simulation and inspect waveforms/scopes.
