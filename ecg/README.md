# ECG Filter Design Files

This folder contains simulation/design files for ECG signal filtering, including low-pass and notch filtering stages.

## Contents

- `LowPass140Hz.TSC`: low-pass filter circuit simulation file
- `NOTCH.TSC`: notch filter circuit simulation file
- `1_P2221.pdf`: schematic/output export document
- `material/*.jpg`: supporting figures/screenshots

## Tools

- TINA-TI

## How To Run

1. Open `LowPass140Hz.TSC` or `NOTCH.TSC` in TINA-TI.
2. Run transient and/or AC analysis to inspect filtering behavior.
